# 📊 Data Analytics Portfolio

## 🚀 Overview
Welcome to my project hub! This repository shows how I work with data from start to finish. It includes projects where I pull data from databases, clean and analyze it using Python, and build visual dashboards to find useful business insights.

---

## 📂 Project Directory

### 1. 🐍 Python Fundamentals
* **Folder:** `/python-basics`
* **What I used:** Core Python, Custom Classes (OOP), Error Handling
* **What it does:** Showcases basic programming logic, interactive tools (like a Bank Account system), and dynamic sorting scripts.

### 🔢 2. Numerical Python & Data Wrangling
* **Folder:** `/numerical-analysis`
* **What I used:** Pandas, NumPy
* **What it does:** Focuses on cleaning messy datasets, handling missing values, and doing calculations on large rows of data.

### 🗄️ 3. SQL Databases (RDBMS)
* **Folder:** `/sql-queries`
* **What I used:** Relational Databases, SQL Queries
* **What it does:** Demonstrates how I extract specific information from tables using Joins, Subqueries, and Data Aggregations.

### 📈 4. Data Visualization & Dashboards
* **Folder:** `/visualizations`
* **What I used:** Power BI / Tableau / Matplotlib
* **What it does:** Displays interactive dashboards and charts that track key performance metrics and business trends clearly.
